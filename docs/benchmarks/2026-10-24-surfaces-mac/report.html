Crab Breeze · building-research · Apple M4 Max, windowed 120 Hz

Textured Buildings Benchmark

City combat (--bench defence, raiders spawning in the streets), three builds interleaved in one sitting, 2 runs each, windowed at 1920 x 1080 on the M4 Max's 120 Hz display, nothing else running. Not the RTX 3070.

The owner's targets are 120 fps (8.3 ms) at the 95th percentile and never below 60 fps (16.7 ms) at the 99th.

Run 2026-10-24 19:40Build 0c340a7 + uncommitted changes GPU Apple M4 Max (Metal)View in the window, presented through the GPU

Findings

  1. The textured build is no slower than the flat one, and steadier. p50 16.67 against 16.64 ms, p99 30.53 against 35.30 ms, freezes over 50 ms 0 against 8, worst frame 44 against 68 ms.
  2. The redraw cost fell about tenfold. Slow redraw_buildings frames: 742-1266 a run before, 48-150 after. Most of it was MikkTSpace tangent generation, which the old build already ran on the skin meshes; the boxes' tangents are now written straight from their planar UVs (test: planar_tangents_match_mikktspace_on_a_box).
  3. An earlier textured build without that fix was much worse: p95 38.6 against 23.3 ms and 494 freezes against 9 (same sitting style, 2 runs each), because every hit ran MikkTSpace on up to 8 meshes per band.
  4. SSAO costs nothing measurable here: new-ssao p95 21.45 ms (spread 0.21), p99 25.00 ms, against new's p95 26.82 ms (spread 5.70) and p99 30.53 ms; the difference is inside new's own spread, so it is not a speedup either. One 373 ms freeze in a new-ssao run, at the wave's start.
  5. Still over the 120 fps target: every build's p50 sits at 16.6 ms on this display.

How this was measured

  • Apple M4 Max, not the RTX 3070. The scripted pilot's fight differs run to run (its mech was destroyed in every run, city damage 2-6 %), so two runs a build is a small sample.
  • Peak process memory: new 1380 MB against before 1370 MB, inside run noise; new-ssao 1471 MB (the normal prepass and SSAO buffers). The texture sets are about 134 MB on the GPU (design estimate), not measured here.

Each run starts the game fresh, plays the scripted take in its window, drawn and presented through the GPU as a player sees it (CLAUDE.md section 7: no offscreen perf rendering), and throws away its first 10 s. A run that crashed, timed out or never finished its take is marked invalid and left out. Traces are binned to 0.1 s: the faint line is each bin's worst frame, the solid line its median.
