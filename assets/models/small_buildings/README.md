# Small buildings

Seventeen houses and small businesses as game kits: `<id>.glb` (LOD0, LOD1, LOD2), `<id>.pieces.json`
(the destruction table) and `manifest.json`. Generated by `tools/buildings/export_small_buildings.cjs`
from `docs/mockups/small_buildings_kit.js`; do not edit by hand. How to load, break and optimise
them: `docs/design/small-buildings-kit.md`.
