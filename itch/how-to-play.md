# STRATOSTACEAN: How to Play

Walk to your mech, climb in, fight from the cockpit.

## On Foot

| Key | Action |
|---|---|
| W A S D | Walk |
| Mouse | Look |
| Shift | Run |
| E | Board the mech |

## Piloting

| Key | Action |
|---|---|
| W / S | Throttle |
| A / D | Turn |
| Mouse | Aim torso |
| X | Throttle to zero |
| 1 / 2 / 3 | Walk / Skate / Jet |
| Shift | Toggle skates |
| Space (hold) | Rocket lift |
| C | Dive / sink |
| Ctrl (hold) | Free look, click screens |
| E | Climb out |

## Combat

| Key | Action |
|---|---|
| Left mouse | Fire selected weapon |
| Right mouse | Cannon |
| Mouse wheel / ] | Change weapon |
| Q | Next target |
| F | Missile at lock |
| Z / V | Left / right punch |
| Tab | Close combat on / off |

## Other

| Key | Action |
|---|---|
| M | Mail and jobs |
| Esc | Menu |
